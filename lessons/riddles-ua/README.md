# 🦉 Загадки (украинская версия)

Украинская версия [🦉 Загадок](../riddles): большой динамик читает загадку, ребёнок собирает отгадку из слогов. На сайте — `/ua/riddles/`.

Русские загадки в стихах не переводились — при переводе пропала бы рифма. Здесь 33 украинские народные загадки («Без рук, без ніг, а ворота відчиняє» — «Вітер»). Отгадки по уровням: 🌼 Узлісся (2–3 части), 🍄 Лісова стежка (4), 🦉 Совине дупло (5 и больше).

## Что где лежит

| Файл | Что это |
|---|---|
| `lesson.json` | название, раздел, `"lang": "ua"`, `uses: ["russian"]` — звуки слогов |
| `game.json` | `"mode": "riddle"`, уровни и тексты окон |
| `data/riddles.json` | загадки: `id`, строки `lines`, отгадка `answer`, текст для озвучки `tts` (`+` перед ударной гласной, `<[small]>` — пауза между строками) и голос `voice` |
| `audio/<id>.mp3` | озвученные загадки; загадка без звука в игру не попадает |
| `theme.css` | лесные цвета — копия темы `riddles` |

## Озвучка

Три украинских голоса ElevenLabs вперемешку, поровну: `olga` (мягкий, для детских аудиокниг), `yaroslava` (чёткий), `alex` (Alex Nekrasov, мужской). Голос загадки — её поле `voice`; список голосов — `UA_ELEVENLABS_VOICES` (см. `.env.example`). Модель — `eleven_multilingual_v2`, язык `uk`.

Озвучивает тот же скрипт, что и русские загадки, с `--lesson riddles-ua`:

```bash
python3 ../riddles/tools/voice.py --lesson riddles-ua --dry-run      # что будет озвучено и каким голосом
python3 ../riddles/tools/voice.py --lesson riddles-ua                # только недостающие
python3 ../riddles/tools/voice.py --lesson riddles-ua --redo vovk    # переозвучить загадку
```

Неверное ударение — поставьте `+` перед ударной гласной в `tts` («ком+орі») и переозвучьте её через `--redo`. Новая загадка — запись в `data/riddles.json` с новым `id`; голос лучше выбрать тот, которого меньше (видно в `--dry-run`).
