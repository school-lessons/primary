# 🎮 Секрети Роблокса (украинская версия)

Украинская версия [🎮 Секретов Роблокса](../read-roblox): ребёнок читает вслух короткую фразу про Роблокс, браузер слушает (`uk-UA`), а в награду голос рассказывает секрет, совет или загадку. На сайте — `/ua/read-roblox/`.

Те же 100 пар, переведённые на украинский, те же уровни по длине фразы: «Нуб» 🟨 — 5–7 слов, «Профі» 😎 — 8–9, «Легенда» 👑 — 10 и больше. Названия игр написаны кириллицей, чтобы ребёнок мог их прочитать: «Роблокс», «робукси», «Дорс», «Адопт Мі», «Піґі».

Игра собирается общим движком [read-game](../read-game) в режиме `sentence` (раздел «Украинские уроки» в его README): латиницу, которую иногда пишет распознавание, и числа он читает по-украински.

## Что где лежит

| Файл | Что это |
|---|---|
| `lesson.json` | название, раздел, `"lang": "ua"`, команда сборки |
| `game.json` | `"mode": "sentence"`, уровни и тексты окон |
| `data/pairs.json` | пары: `id`, фраза для чтения `read`, награда `reward` (и `tts` у `023` — как произносить команды «/e dance») |
| `audio/<id>.mp3` | озвученные награды; пара без звука в игру не попадает |
| `theme.css` | цвета кубиков — копия темы `read-roblox` |

## Озвучка

Три украинских голоса ElevenLabs по очереди (Olga, Yaroslava, Alex Nekrasov — `UA_ELEVENLABS_VOICES`), модель `eleven_multilingual_v2`, язык `uk`. Голос пары зависит от её места в списке, поэтому переозвученная пара остаётся тем же голосом. Все 100 наград — около 18 600 символов, больше, чем остаётся от месячного лимита, поэтому озвучивали частями: `--limit N` берёт первые N пар без звука.

```bash
python3 ../read-roblox/tools/voice.py --lesson read-roblox-ua --dry-run      # что осталось и каким голосом
python3 ../read-roblox/tools/voice.py --lesson read-roblox-ua --limit 10     # следующие 10 пар
python3 ../read-roblox/tools/voice.py --lesson read-roblox-ua --redo 004     # переозвучить пару
```

Факты, которые стареют (сколько игроков, рекорды), стоит перепроверять — как и в русском уроке.
