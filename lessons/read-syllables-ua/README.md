# 🐷 Збери слово (украинская версия)

Украинская версия [🐷 Собери слово](../read-syllables): ребёнок собирает из слогов слова украинской сказки «Три поросятка» и строит три домика. На сайте — `/ua/read-syllables/`.

Урок работает на общем движке [read-game](../read-game) — там описано, как устроена игра и как он говорит по-украински (раздел «Украинские уроки»).

## Что где лежит

| Файл | Что это |
|---|---|
| `lesson.json` | название, раздел на главной, `"lang": "ua"`, команда сборки |
| `game.json` | уровни (Солом’яний будиночок, Будиночок із гілок, Кам’яний дім), тексты окон; `"pictures": "read-syllables"` — картинки русского урока |
| `data/text1.txt` | сказка «Три поросятка» по-украински — перевод русского текста урока |
| `data/words.txt` | слова сказки по частоте — из `text1.txt` |

Картинки не рисовались заново: это картинки [read-syllables](../read-syllables). Какому украинскому слову какая картинка — в [read-syllables/data/ua.tsv](../read-syllables/data/ua.tsv) («русское слово → украинское»). Все 75 слов с картинками в украинской сказке есть; «дах» из одного слога, и в игру не попадает.

Звуки слогов — русские, из [lessons/russian](../russian): украинский слог играет русский звук, который звучит так же («ми» → «мы», «мі» → «ми», «ме» → «мэ»). Слога без своего звука («нэ», «кы»…) звучат по буквам.

## Собрать заново

```bash
python3 ../read-game/tools/words.py data/text1.txt -o data/words.txt   # после правки сказки
node ../read-game/game/build_scripts/build.mjs .                         # → build/
```

Новое слово с картинкой — строка в `read-syllables/data/ua.tsv`; слово должно быть в сказке, иначе в игру оно не попадёт.
