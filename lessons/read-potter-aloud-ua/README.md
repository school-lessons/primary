# 🎤 Прочитай вголос (украинская версия)

Украинская версия [🎤 Прочитай вслух](../read-potter-aloud): ребёнок читает вслух слово из «Гарри Поттера», разбитое на слоги, а браузер слушает и ставит звёздочку. На сайте — `/ua/read-potter-aloud/`.

Слова — те же 73, что в [🪄 Чарівних словах](../read-potter-ua): переводы из `potter/data/ua.tsv`. Распознавание речи — `uk-UA` (Chrome, Edge, Safari; без него появляется кнопка «👍 Вийшло»). Как проверяется чтение — как в русском уроке, только с украинским алфавитом.

| Файл | Что это |
|---|---|
| `lesson.json` | название, раздел, `"lang": "ua"`; `uses` нет — во время игры урок ничего не берёт из общих папок |
| `game.json` | `"mode": "aloud"`, слова из `"potter"`, уровни и тексты окон |
| `theme.css` | копия темы `read-potter` |

```bash
node ../read-game/game/build_scripts/build.mjs .    # → build/
```
