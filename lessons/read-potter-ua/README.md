# 🪄 Чарівні слова (украинская версия)

Украинская версия [🪄 Волшебных слов](../read-potter): ребёнок собирает из слогов 73 слова из «Гарри Поттера» и добирается до Гоґвортсу. На сайте — `/ua/read-potter/`.

Урок работает на общем движке [read-game](../read-game) (раздел «Украинские уроки»). Слова — переводы слов общей папки [lessons/potter](../potter) из её `data/ua.tsv`, картинки — её же: имена и названия как в украинском переводе издательства «А-ба-ба-га-ла-ма-га» (Гаррі, Геґрід, Гоґвортс, квідич).

| Файл | Что это |
|---|---|
| `lesson.json` | название, раздел, `"lang": "ua"`, `uses`: `russian` (звуки слогов) и `potter` (картинки) |
| `game.json` | слова из `"potter"`, уровни (Алея Діаґон, Гоґвортс-експрес, Гоґвортс), тексты окон |
| `theme.css` | цвета школы волшебства — копия темы `read-potter` |

```bash
node ../read-game/game/build_scripts/build.mjs .    # → build/
```
