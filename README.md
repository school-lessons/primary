## Как устроено

```
lessons/
  <папка-урока>/
    lesson.json      — название, раздел, иконка, как собрать
    README.md        — что за урок и как пересобрать его материалы
    game/            — код урока (если его нужно собирать)
    tools/           — утилиты, которые готовят материалы: озвучка, картинки, страницы проверки
    data/            — исходные тексты и списки
    audio/, images/  — готовые звуки и картинки
  <общая-папка>/     — материалы нескольких уроков, с shared.json вместо lesson.json (например, english/, russian/, potter/)
site/
  index.html         — главная: выбор языка
  home.html          — шаблон списка уроков (ru/index.html)
  manifest.webmanifest, sw.js, icon*.png — всё для приложения (PWA), см. ниже
build_scripts/
  build.mjs          — собирает весь сайт в _site/
  icons.mjs          — рисует PNG-иконки приложения из site/icon.svg
.github/workflows/
  pages.yml          — сборка и публикация на GitHub Pages
.env.example         — какие ключи нужны утилитам (сам .env в git не попадает)
```

Сайт после сборки:

```
_site/
  index.html              — главная: выбор языка
  ru/
    index.html            — русские уроки по разделам
    read-syllables/       — урок «Собери слово»
    …
  ua/                     — украинские уроки: index.html, read-syllables/ («Збери слово»), …
  russian/, english/, …   — общие материалы: одни на все языки
  read-syllables/         — переадресация со старого адреса на ru/read-syllables/
  sw.js, manifest.webmanifest, icon*.png
```

Раньше уроки лежали прямо в корне (`/read-syllables/`). Сборка оставляет на старых адресах маленькие страницы, которые переводят на `/ru/<урок>/`, так что старые ссылки и закладки работают. Папку урока нельзя назвать `ru`.

## Собрать и посмотреть локально

Нужен Node.js (и Python 3 — для локального сервера).

```bash
npm run serve            # собрать всё и открыть на http://localhost:8090
npm run build            # только собрать в _site/
node build_scripts/build.mjs --no-build   # пересобрать главную, не пересобирая уроки
```

## Добавить урок

1. Создайте папку `lessons/<папка>/` — латиницей, через дефис: `math-addition`, `math-multiplication`. Это же имя будет в адресе страницы: `/ru/<папка>/`.
2. Положите в неё `lesson.json`:

   ```json
   {
     "title": "Сложение до 10",
     "description": "Тренажёр: складываем числа до десяти.",
     "subject": "Математика",
     "icon": "➕",
     "order": 100
   }
   ```

   | Поле | Что это |
   |---|---|
   | `title` | название на карточке |
   | `description` | одна-две фразы, что делаем |
   | `subject` | раздел на главной: «Чтение», «Математика»… Разделы создаются сами |
   | `icon` | эмодзи для карточки |
   | `order` | порядок: меньше — выше. Необязательно |
   | `build` | команда сборки, запускается в папке урока: `"cd game && npm ci && npm run build"`. Необязательно |
   | `publish` | какую папку выложить после сборки, например `"game/build"`. По умолчанию — саму папку урока |
   | `hidden` | `true` — урок собирается, но не показывается на главной (черновик) |
   | `uses` | общие папки, из которых урок берёт файлы: `["english"]`. Необязательно, см. «Общие материалы» |
   | `lang` | язык урока: `"ru"` (по умолчанию) или `"ua"`, см. «Языки» |
   | `ua` | украинская версия из той же папки: `{ "title", "description", "subject", "publish": "build-ua" }`, см. «Языки» |

3. Если урок — просто страница без сборки, хватит `index.html` рядом с `lesson.json`: всё из папки уйдёт на сайт.
4. Добавьте `README.md` урока: что это, как запустить, как пересоздать звуки и картинки.
5. `npm run serve` — проверить, что карточка появилась и урок открывается.

## Языки

У каждого языка своя папка на сайте и свой список уроков: `/ru/`, `/ua/`. На главной (`/`) — выбор языка большими кнопками, со списка уроков на него ведёт кнопка «🌐 Язык» / «🌐 Мова». Тексты списка и кнопки 🏠 для каждого языка — в `LANGUAGES` в [build_scripts/build.mjs](build_scripts/build.mjs).

- Урок, у которого есть перевод, собирается из той же папки дважды: в `lesson.json` есть блок `"ua"` (`title`, `description`, `subject`, `publish`), и корневая сборка запускает его `build` второй раз с `LESSON_LANG=ua` — движок пишет украинскую версию в `build-ua/` (общие функции — [build_scripts/i18n.mjs](build_scripts/i18n.mjs)). Так переведены математика, дроби, физика, английский и «Мерлин читает».
- Урок, где по-украински другое содержание (чтение), — отдельная папка с `"lang": "ua"` в `lesson.json`; имя папки кончается на `-ua`, и в адресе этого окончания нет: `lessons/read-syllables-ua` → `/ua/read-syllables/`. Так у русского и украинского урока одинаковые адреса, только в разных папках языка.
- Общие папки (`russian/`, `potter/`, …) лежат в корне сайта одни на все языки.
- Тексты кнопок и сообщений движка — по-русски и по-украински — в его `strings.json` (у движка чтения — [lessons/read-game/game/strings.json](lessons/read-game/game/strings.json)); язык урока движок берёт из его `lesson.json`.
- Украинские уроки чтения показывают картинки русских уроков (переводы их слов — в `data/ua.tsv`) и играют русские звуки слогов, которые звучат так же. Подробно — в [lessons/read-game/README.md](lessons/read-game/README.md#украинские-уроки).

## Общие материалы

Если картинки и звуки нужны нескольким урокам, их не копируют, а кладут в общую папку `lessons/<папка>/` с файлом `shared.json` вместо `lesson.json`:

```json
{
  "title": "Английский: слова, картинки и звуки",
  "publish": ["audio", "images"]
}
```

- Сборка публикует её один раз как `_site/<папка>/`, в корне, а не в папке языка: только перечисленные в `publish` подпапки, или всю папку, если `publish` нет. На главной она не показывается.
- Урок пишет в своём `lesson.json` `"uses": ["<папка>"]` и загружает файлы по относительному пути: `../../<папка>/…` на сайте (из `_site/ru/<урок>/`), а из локальной сборки — до `lessons/`: `../../../<папка>/…` из `lessons/<урок>/game/build/`, `../../<папка>/…` из `lessons/<урок>/build/`.
- Service worker сохраняет общую папку вместе с каждым уроком, который её указал, поэтому урок работает без интернета.

Примеры — [lessons/english](lessons/english): её используют «Скажи по-английски» и «Найди картинку»; [lessons/russian](lessons/russian) — звуки букв и слогов для всех уроков чтения; [lessons/potter](lessons/potter) — слова и картинки для «Волшебных слов» и «Прочитай вслух»; [lessons/english-phrases](lessons/english-phrases) — фразы и их звуки для «Переведи на русский», «Скажи фразу по-английски» и «Собери фразу»; [lessons/english-tenses](lessons/english-tenses) — предложения и звуки для двух уроков времён.

## Приложение (PWA)

Сайт можно установить как приложение — на телефон, планшет или компьютер — и заниматься без интернета.

- **Установить:** на iPhone/iPad — Safari → «Поделиться» → «На экран „Домой“»; на Android и в Chrome на компьютере — меню → «Установить приложение» (или значок установки в адресной строке).
- **Без интернета:** главная и список уроков сохраняются сразу, а урок — целиком, со звуками и картинками, при первом открытии. Значит, перед поездкой достаточно один раз открыть нужные уроки с интернетом.
- **Обновления:** после публикации приложение докачивает только изменённые файлы. Новая версия появляется со второго открытия: первое подтягивает её в фоне.
- **Кнопка 🏠:** сборка сама добавляет на страницу каждого урока кнопку «Все уроки» в левом нижнем углу — она ведёт к списку уроков своего языка (в установленном приложении нет кнопки «назад» браузера). На телефоне видна только 🏠. Внизу страницы урока стоит оставлять ~70px свободного места.
- Урокам для этого ничего делать не нужно: манифест, service worker и кнопку подключает корневая сборка.

Устроено так: [site/manifest.webmanifest](site/manifest.webmanifest) — название, цвета и иконки; [site/sw.js](site/sw.js) — service worker, сборка вписывает в него список всех файлов сайта с хэшами. Сайт живёт в папке `/primary/` общего домена организации `school-lessons.github.io`, поэтому кэши service worker называются с префиксом `primary` и он удаляет только их — офлайн-копии соседних сайтов организации не трогает. Иконка рисуется в [site/icon.svg](site/icon.svg); после её правки пересоздайте PNG (нужен Google Chrome):

```bash
node build_scripts/icons.mjs
```

Service worker работает только по `https://` и на `localhost`, поэтому локально приложение проверяется через `npm run serve` (порт 8090 — отдельный, чтобы не мешать серверам утилит уроков на 8000). Если локально видна старая версия — обновите страницу ещё раз или в Chrome: DevTools → Application → Service workers → Unregister.

## Ключи

Ключи **в репозиторий не кладём**. Утилиты уроков (озвучка, картинки) берут их из файла `.env` в корне репозитория:

```bash
cp .env.example .env     # и впишите свои ключи
```

Какие ключи нужны и где их взять — в [.env.example](.env.example). Сайту ключи не нужны: в репозитории лежат уже готовые звуки и картинки, сборка и публикация обходятся без них.

## Публикация

Каждый push в `main` запускает [pages.yml](.github/workflows/pages.yml): он собирает сайт (`node build_scripts/build.mjs`) и выкладывает `_site/` на GitHub Pages. Запустить вручную — вкладка Actions → «Публикация на GitHub Pages» → Run workflow.

Один раз нужно включить Pages: **Settings → Pages → Source: GitHub Actions**.
